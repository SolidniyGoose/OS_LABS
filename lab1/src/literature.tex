\subsection{Системные вызовы (strace)}
Для анализа системных вызовов можно использовать утилиту strace:
\begin{verbatim}
$ strace -f -o trace.log ./parent
\end{verbatim}

В файле trace.log будут видны все системные вызовы, включая:
\begin{itemize}
    \item \texttt{openat()} — открытие файла
    \item \texttt{pipe()} — создание каналов
    \item \texttt{fork()} — создание дочернего процесса
    \item \texttt{dup2()} — перенаправление дескрипторов
    \item \texttt{execve()} — запуск дочерней программы
    \item \texttt{read()/write()} — чтение/запись в каналы
    \item \texttt{wait4()} — ожидание завершения потомка
\end{itemize}
